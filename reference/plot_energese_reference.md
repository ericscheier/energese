# Plot the canonical Energese reference chart

Reproduces Wikipedia's canonical H.T. Odum Energy Systems Language
symbol legend (<https://commons.wikimedia.org/wiki/File:Energese.jpg>,
Sholto Maud's Visio stencil) using this package's ggplot2 Geoms. All ten
symbols are drawn in the same top-to-bottom order as the Wikipedia
chart, each in its own rounded box with its canonical label below.

## Usage

``` r
plot_energese_reference()
```

## Value

A `ggplot` object.

## Details

Use this to confirm that the package produces faithful Odum ESL
geometry, or as a "cheat sheet" figure in publications.
